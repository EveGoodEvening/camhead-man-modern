# AGENTS.md

Three.js (WebGLRenderer) tiny-planet urban weird-tales puzzle game about a man whose head is a phone camera.
Design docs live in `docs/` (GDD, ART_DIRECTION, TECH_NOTES, ARCHITECTURE).

## Lessons

- [orchestrator] NEVER wait with `until ! pgrep -f "<pattern>"; do sleep N; done` — the waiting shell's own command line contains the pattern, so pgrep always matches itself and the loop never ends (two agents hung 30+ min this way). Wait on the PID instead (`while kill -0 $PID 2>/dev/null; do sleep 5; done`), or run the command in the foreground / with `run_in_background` and wait for its completion notification.

- On SwiftShader, HalfFloat render targets ~2x slower than UnsignedByte (65 vs 40 ms/frame at 720p); use UnsignedByte + `texture.colorSpace = SRGBColorSpace` for color targets. EffectComposer defaults to HalfFloat.
- r186: `PCFSoftShadowMap` removed (falls back to PCF with warning), `Clock` deprecated -> `Timer`, `WebGLMultipleRenderTargets` gone -> `new WebGLRenderTarget(w,h,{count})` + `.textures[i]`.
- MeshToonMaterial/Lambert lighting: light intensity π = full albedo (measured). Keep sun + ambient ≈ π with `NoToneMapping`.
- Vitest picks up Playwright `e2e/*.spec.ts` unless `test.include: ['src/**/*.test.ts']` is set.
- Headless Chromium AudioContext starts `running` without a gesture; tests can't detect a missing unlock.
- three r186: `PCFSoftShadowMap` is deprecated (use `BasicShadowMap`/`PCFShadowMap`). MRT = `new WebGLRenderTarget(w,h,{count:2})` + `rt.textures[i]`. `MeshToonMaterial` lacks `shadowmask_pars_fragment`: inject it for `getShadowMask()`. Built-in materials already declare location 0 (`pc_fragColor`); inject only `layout(location = 1) out highp vec4 gInfo;`. Every main-pass material must write location 1, so there is no `scene.background` and no transparent materials there.
- WebGL writes depth only while the depth test is enabled. A fullscreen pass that writes `gl_FragDepth` needs `depthTest: true, depthFunc: AlwaysDepth, depthWrite: true`.
- Screen-space outline "boil": jitter the center tap together with the neighbours. Jittering only the neighbours breaks the 1/z-Laplacian plane test and speckles grazing ground.
- Low-frequency value noise with few lattice cells is badly biased; rank-equalize generated noise channels so thresholds equal area fractions.
